# Folder Text Viewer

Folder Text Viewer は、指定したフォルダ内のテキスト系ファイルを一覧表示し、内容の確認・コピー・保存を行うためのシンプルな Python/Tkinter ツールです。

## できること

- フォルダ内のテキストファイルを一覧表示
- ファイル名で 2 条件フィルター
- AND / OR 条件で絞り込み
- 本文プレビュー表示
- JSON の整形表示 / 生表示の切り替え
- 本文コピー
- ファイルパスコピー
- 本文全選択
- 表示中テキストの保存

## 対応拡張子

- `.txt`
- `.json`
- `.md`
- `.log`
- `.csv`
- `.yaml`
- `.yml`

## 動作環境

- Python 3.x
- Tkinter が使える環境

Linux では環境によって Tkinter が別パッケージの場合があります。

例:

```bash
sudo apt install python3-tk
```

## 起動方法

```bash
python3 folder_text_viewer.py
```

## 使い方

### 1. 起動する

スクリプトを実行すると、ウィンドウが開きます。

画面構成は次の通りです。

- 上部: フォルダ指定欄
- 左側: ファイル一覧
- 右側: テキスト内容表示
- 下部: ステータス表示

### 2. フォルダを選ぶ

上部の `参照` ボタンを押して、確認したいフォルダを選びます。

または、フォルダパスを直接入力して Enter でも読み込みできます。

### 3. ファイル一覧を見る

選んだフォルダ直下にある対応拡張子のファイルが、左側に一覧表示されます。

新しいファイルほど上に表示されます。

### 4. ファイルを開く

左側の一覧でファイル名をクリックすると、右側に本文が表示されます。

### 5. フィルターで絞り込む

`Filter 1` と `Filter 2` に文字を入力すると、ファイル名で絞り込みできます。

- `AND`: 両方の文字を含むファイルのみ表示
- `OR`: どちらかの文字を含むファイルを表示

`絞込` ボタンで適用、`クリア` ボタンで解除できます。

## JSON 表示

`.json` ファイルを開いたときは、右上の `JSON表示` で表示方法を切り替えできます。

- `整形`: 読みやすくインデントして表示
- `生`: 元の文字列そのままで表示

## ボタン説明

- `参照`: フォルダを選択
- `再読込`: 現在のフォルダを再読み込み
- `本文コピー`: 表示中の本文をコピー
- `パスコピー`: 表示中ファイルのパスをコピー
- `全選択`: 本文をすべて選択
- `テキスト保存`: 表示中の内容を別ファイルとして保存

## ショートカットキー

- `Ctrl + F`: Filter 1 にカーソル移動
- `Ctrl + O`: フォルダ選択
- `Ctrl + R`: 再読込
- `Ctrl + A`: 本文を全選択
- `Ctrl + C`: 本文内の選択テキストをコピー

## 注意点

- 読み込むのはフォルダ直下のファイルのみです
- サブフォルダ内のファイルは自動では読み込みません
- 基本は UTF-8 で読み込みます
- UTF-8 で読めない場合は UTF-8-SIG も試します
- 対応拡張子以外のファイルは一覧に出ません

## こんな用途に向いています

- JSON やログファイルをまとめて確認したい
- テキストファイルを素早く切り替えて見たい
- フォルダ内の設定ファイルを名前で絞り込みたい
- 内容を見ながらコピーや保存をしたい
