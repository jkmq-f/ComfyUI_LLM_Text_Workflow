# Outfit Danbooru Style Dictionary

Broad curated clothing-tag dictionary for the outfit node.

- Tag format: Danbooru-like underscored general tags
- Scope: safe/common outfit tags only
- Use case: random selection by style, season-aware outfit assembly, prompt building
- Important: this is not literally every Danbooru clothing tag. Danbooru's tag universe is too large and changes over time.

Main files:
- data/outfit_danbooru_style_dictionary.json
- data/outfit_danbooru_style_dictionary_flat.txt
