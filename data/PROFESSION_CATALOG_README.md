# Profession Catalog

This bundle includes an expanded profession catalog for the outfit generator.

- Total professions: 1934
- Schema: list of entries with `key`, `label_en`, `label_ja`, `archetype`, `aliases`, `aliases_ja`
- Archetypes used: 12

The outfit node can use these professions as direct inputs or as random candidates.


Added in this build:
- idol / K-pop / J-pop / virtual idol / trainee professions
- fantasy professions such as adventurer, knight, mage, alchemist, blacksmith, dragon rider
- sci-fi professions such as mech pilot, starship pilot, netrunner, android technician, fleet officer
